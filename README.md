# Валидатор банковских счетов России

Офлайн-валидатор для проверки корректности российских банковских счетов с автодополнением БИК и названий банков.

## ✨ Возможности

- **Автодополнение БИК** - поиск по коду или названию банка
- **Валидация счетов** - проверка корректности 20-значных номеров
- **Полностью офлайн** - работает без интернета
- **Современный интерфейс** - красивый и удобный дизайн
- **База данных БИК** - более 1499 банковских кодов

## 🚀 Использование

### Простой запуск
1. Откройте файл `rus_acc_validator.html` в любом современном браузере
2. Начните вводить БИК или название банка для автодополнения
3. Введите 20-значный номер счета
4. Нажмите "Проверить" для валидации

### Тестирование
- Нажмите "Тест загрузки БИК" для проверки загрузки данных
- Должно показать "1499 записей загружено"

## 🔧 Конвертер данных

### XML → JavaScript
Для обновления базы БИК используйте скрипт `bic_xml2js.py`:

```bash
python3 bic_xml2js.py -i ваш_файл.xml -o bic_data.js
```

### Формат входных данных
- **XML файл** в формате ЦБ РФ (ED807)
- **Автоматическое извлечение** БИК и названий банков
- **Генерация** готового JavaScript файла

## 📊 Алгоритм валидации

Валидатор использует официальный алгоритм ЦБ РФ:
1. **Проверка длины** - счет должен содержать ровно 20 цифр
2. **Извлечение контрольных цифр** из БИК (позиции 7-9)
3. **Расчет контрольной суммы** с весами [7,1,3,7,1,3,7,1,3,7,1,3,7,1,3,7,1,3,7,1,3,7,1]
4. **Проверка делимости** на 10

## 🔄 Обновление данных

Для обновления базы БИК:
1. Скачайте новый XML файл с сайта ЦБ РФ
2. Запустите конвертер: `python3 bic_xml2js.py`
3. Замените `bic_data.js` новым файлом
4. Обновите страницу в браузере

## 📞 Поддержка

При возникновении проблем:
1. Проверьте консоль браузера (F12)
2. Убедитесь, что файл `bic_data.js` существует
3. Проверьте корректность XML файла
